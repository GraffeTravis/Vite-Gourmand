# Décisions à préparer avant les lots concernés

20 octobre 2026. Complément de la [feuille de route](FEUILLE-DE-ROUTE.md). D01 et D02 ont été validées explicitement par le porteur du projet dans le chat de développement ; D03 a été précisée partiellement. Les autres propositions restent ouvertes.
